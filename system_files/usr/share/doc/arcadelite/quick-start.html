Welcome to ArcadeLite

A quiet daily desktop that wakes the NVIDIA GPU when a game needs it.

1. Install your game libraries

Open ArcadeLite Setup from the application menu and choose Install Steam, Heroic, and Lutris. They are installed per user as Flatpaks and do not modify the atomic host.

2. Launch on the right GPU

Store clients normally choose the discrete GPU for games. For a standalone executable, use arcadelite-game --nvidia -- /path/to/game. Add --hud to show MangoHud. Choose --integrated for lightweight games and better battery life.

3. Updates that can go backward

ArcadeLite installs a complete new system deployment and keeps the previous one. Inspect it with bootc status. If an update fails, select the previous deployment in the boot menu or run sudo bootc rollback from a working session.

Useful controls

Press Meta to open the application launcher. Search for System Monitor, GOverlay, ArcadeLite Setup, or ArcadeLite System Report. File indexing is off by default; it can be enabled in System Settings → Search.

Before a long gaming session

Connect AC power, update the system, and keep laptop vents clear. ArcadeLite intentionally avoids overclocking and permanent performance mode. GameMode applies temporary optimizations only while a game is running.
